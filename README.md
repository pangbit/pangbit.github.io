# pangbit.github.io

An interactive terminal-based creative playground. Type commands to trigger visual effects.

## Commands

| Command | Effect |
|---------|--------|
| `matrix` | ASCII symbol digital rain |
| `stars` | Particle starfield flythrough (mouse steers) |
| `life` | Conway's Game of Life (click to draw cells) |
| `snake` | Pixel snake game (ESC to exit) |
| `stop` | Stop current effect |
| `clear` | Clear terminal |
| `help` | Show available commands |

## Tech

Pure HTML/CSS/JS + Canvas 2D. Zero dependencies, no build tools.
